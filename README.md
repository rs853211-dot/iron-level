# Iron Level

Фитнес-RPG для айфона: персонаж растёт вместе с твоими рабочими весами.

## Запуск

Дважды кликни по `index.html`: приложение откроется в браузере. Сборка и зависимости не нужны.

## Работа с Claude Code

```powershell
cd $HOME\workspace\iron-level
claude
```

Контекст проекта, правила расчёта XP и правила дизайна лежат в `CLAUDE.md`. Claude Code читает этот файл сам.
