# Iron Level

Фитнес-RPG для айфона. Персонаж растёт вместе с рабочими весами владельца: за подходы, рекорды и задания начисляется XP, растут уровни, недельные серии и достижения. Есть журнал тренировок, прогресс по группам мышц и ИИ-тренер. Сначала приложение для себя, потом — показать своему залу (Crunch Fit Berlin-Lichtenberg).

Язык интерфейса — русский. Обращение к пользователю на «ты».

## Как устроено сейчас

- Всё приложение — один файл `index.html`: CSS, разметка и ванильный JS без сборки и зависимостей. Единственный внешний ресурс — шрифт Inter с Google Fonts.
- Запуск локально: `python3 -m http.server 8000` (на Windows — `python -m http.server 8000`) и открыть `http://localhost:8000`.
- `manifest.webmanifest` и `icons/` — чтобы при хостинге (например, GitHub Pages) Safari ставил на экран «Домой» настоящую иконку и открывал без адресной строки.
- Приложение изначально жило как артефакт на claude.ai. Там у него были `window.claude.use("db")` (личное хранилище пользователя), `use("user")` и `use("sample")` (ИИ-тренер). Вне claude.ai `window.claude` нет, поэтому:
  - данные хранятся в `localStorage` (ключ `ironlevel.v1`, черновик тренировки — `ironlevel.v1.draft`);
  - ИИ-тренер показывает «работает, когда страница открыта в Claude». Чтобы он работал здесь, нужен свой бэкенд с вызовом Claude API (ключ никогда не кладём в клиент).
- Знакомство с приложением: 6 экранов `INTRO` в `index.html`, показываются один раз после создания персонажа (или при первом открытии у существующего пользователя), флаг `ironlevel.v1.intro` в `localStorage`. Снова открыть: «Профиль → Как считается → Как пользоваться». При новых функциях дополнять `INTRO`.
- Программы тренировок: `PROGRAMS` в `index.html` (фулбади, верх-низ, пуш-пул-ноги; у каждого слота список тренажёров по приоритету). Скрытые в «Мой зал» заменяются в `buildDay()` следующим вариантом или любым упражнением той же группы. Тесты — `tests/programs.test.js`.
- Резервная копия: «Профиль → Данные» сохраняет JSON (`{app:"iron-level", version:1, exportedAt, profile, workouts}`), на айфоне через меню «Поделиться». Загрузка из файла заменяет все данные после подтверждения; на экране создания персонажа — сразу («Восстановить из файла»). Проверка файла — `parseBackup()`, тесты — `tests/backup.test.js`: на `http://localhost:8000` выполнить в консоли `(await import('/tests/backup.test.js?'+Date.now())).run()`. При изменении модели данных поднимать `BACKUP_V` и учить `parseBackup` читать старые версии.

## Модель данных

- `profile`: `{name, sex: "m"|"f", bw, height, age, gym, hidden: [exerciseId], custom: [{id, n, g}], createdAt}`
- `workout`: `{id, date: "YYYY-MM-DD", t, exercises: [{ex: exerciseId, sets: [{w: "кг строкой", r: "повторы строкой"}]}]}`; тренировка по программе дополнительно хранит `prog` и `day`.
- `profile.program`: `"fb" | "ul" | "ppl" | null` — выбранная программа. Следующий день программы не хранится, а считается из журнала в `nextDay()`.
- Весь XP, уровни, рекорды, серии и достижения **пересчитываются из журнала** в `derive()`. Ничего производного не храним: удалишь тренировку — опыт честно уменьшится.

## Правила расчёта (менять осознанно)

- XP: подход +5, рекордный подход +25, завершённая тренировка +30, задание дня (3 подхода на отстающую группу) +15, третья и следующие тренировки за неделю ×1,1.
- Уровень L→L+1 требует `100 + 50·(L−1)` XP.
- Рекорд = лучший расчётный 1ПМ по Эпли `w·(1+r/30)`.
- Сила группы 0–100 = лучший 1ПМ ÷ (вес тела × `t` упражнения), обрезано до 1. `t` — уровень «уверенного продвинутого».
- `bw: true` — вес тела + доп. вес; `per: true` — вес одной гантели; `plates: true` — блины на обе стороны (Hammer Strength).
- Серия — недели подряд с 2+ тренировками.
- Ранг группы по силе 0–100: Бронза 0, Серебро 25, Золото 50, Платина 70, Элита 90 (`groupRank()`). Группа «отдыхает», если её качали сегодня или вчера (`recovery()`). Светлота мышцы на персонаже растёт с силой группы (`muscleFill()`), жёлтый остаётся только для «проработано сегодня». Тесты — `tests/insights.test.js`.
- **id упражнений не переименовывать**: по ним читаются сохранённые тренировки.

## Каталог тренажёров

`EX` в `index.html`, зоны `ZONES`: Hammer Strength (рычажные), Life Fitness Insignia (блочные), кроссовер и блоки, свободные веса, свой вес. Это типичный набор этих брендов, а не сверенный список зала. Пользователь может скрывать тренажёры и добавлять свои в «Профиль → Мой зал».

## Дизайн — соблюдать при любых правках

Стиль «true-black flat» из скилла design-taste-frontend (параметры в `docs/design-direction.json`), правки проверены по Vercel Web Interface Guidelines.

- Фон почти чёрный `#0d0d0c`, карточки на шаг светлее. Глубина только светлотой: без теней, рамок у карточек, градиентов, blur и свечения.
- Одна цветовая метка для данных — жёлтый 15-килограммового блина `#f2c230`: XP, рекорды, проработанные сегодня мышцы, текущая неделя. На кнопки, табы и навигацию её не ставить.
- Главная кнопка — белая «пилюля» с тёмным текстом. Остальные — серые.
- Один шрифт Inter, 400/500/600. Заголовок экрана 20px, ведущая цифра 34px, KPI 24px. Цифры — `tabular-nums`.
- Без подписей капсом, без эмодзи, без иконок в цветных плашках, без нумерации 01/02.
- Персонаж (SVG в `figure()`) — главный элемент экрана, размер мышц следует за силой групп.
- Телефон прежде всего: колонка 480px, отступы 16px, кнопки от 44px высотой, safe-area учтены.

## Возможные следующие шаги

1. Офлайн-режим: service worker кэширует `index.html`, шрифт и иконки.
2. Бэкенд для ИИ-тренера и синхронизации между устройствами.
3. Настоящее iOS-приложение: обернуть в Capacitor или переписать на Expo/React Native. Для App Store нужны Mac с Xcode и Apple Developer ($99 в год).
4. Версия для зала: аккаунты клиентов, тренер видит своих подопечных, рейтинг зала.
