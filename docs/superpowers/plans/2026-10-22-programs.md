# Готовые программы тренировок: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** выбрать в профиле одну из трёх базовых программ (фулбади, верх-низ, пуш-пул-ноги) и начинать тренировку дня одной кнопкой, с упражнениями из своего зала и целью по подходам и повторам.

**Architecture:** всё в `index.html`. Справочник `PROGRAMS` лежит рядом с `EX`. Две чистые функции: `nextDay` определяет следующий день по журналу, `buildDay` собирает упражнения дня с учётом скрытых тренажёров. В профиле хранится только выбор `profile.program`. Тренировка, начатая по программе, получает поля `prog` и `day`. По ним `nextDay` понимает, какой день следующий, так что производное, как и раньше, не хранится.

**Tech Stack:** ванильный JS без сборки. Тесты — ES-модули в браузере, как `tests/backup.test.js`.

**Spec:** разговор от 2026-10-22: «выбирать, типа, вот я такой-то, push-pull-legs», и ответ с описанием (три программы, выбор в профиле, кнопка «Сегодня: …» на экране тренировки, замена скрытых тренажёров, следующий день из журнала, XP не меняется).

## Global Constraints

- Без сборки и зависимостей, код приложения только в `index.html`.
- Тексты на русском, на «ты». Без капса, эмодзи и иконок.
- Главная кнопка — `btn primary`, остальные — `btn`, выбор — `.seg` с `aria-pressed`. Жёлтый `#f2c230` только на данных.
- Правила XP, рекордов и силы групп не меняются. Тренировка по программе считается как любая другая.
- id упражнений не переименовывать. Новые поля тренировки (`prog`, `day`) необязательны, старые тренировки без них читаются как раньше.
- Если в файле резервной копии есть `program`, `prog` или `day`, `parseBackup` их сохраняет, но только для известных id из `PROGRAMS`.

## Review Focus

1. **Все варианты слота скрыты в «Мой зал»** (например, нет штанги): берётся первое нескрытое упражнение той же группы из `ALL`, включая свои тренажёры, которого ещё нет в этом дне. Если такого нет, слот пропускается без ошибки. → Задача 1, тесты `fallback-group`, `slot-skipped`.
2. **Две замены приходят к одному упражнению:** в дне нет дублей. → Задача 1, тест `no-duplicates`.
3. **Сменил программу посередине:** `nextDay` смотрит только на тренировки этой программы, на новой программе начинает с первого дня. → Задача 1, тест `switch-program`.
4. **Тренировка из старой копии или с неизвестным `prog`/`day`:** приложение не падает, `nextDay` её игнорирует, `parseBackup` удаляет неизвестные значения. → Задача 1, тест `unknown-day-ignored`; Задача 2, тест `prog-unknown-dropped`.
5. **Идёт незаконченная тренировка, а ты меняешь программу в профиле:** текущая запись не трогается, новая программа действует со следующего старта. → Задача 3, шаг 6.
